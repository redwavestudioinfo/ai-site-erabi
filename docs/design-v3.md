# AIサイト選び v3 — 編集メディアデザイン

更新日：2026-11-22

## なぜ作り直したか
v2は青緑グラデーション、装飾カード、架空のアプリ画面、英語のセクション名など、AI生成テンプレートに見える要素が目立っていた。比較したい読者にとって必要な**料金・無料条件・作り方**が視覚上の主役になっていなかった。

## v3の方向性
- **雑誌・編集記事のように**。グラデーション、過剰な丸角、架空のプレビュー画面を廃止。
- 生成AIを語るサイトではなく、**AIでホームページを作りたい人が条件を比較するサイト**として見せる。
- 背景は紙色、文字は墨色。差し色は少量の赤茶。強調は色面の多用ではなく、余白・大きな見出し・罫線でつける。
- 実在するサービスの未確認ロゴや偽スクリーンショットを使わない。
- 体験していないサービスにレビュー点数・順位・感想をつけない。

## 情報の並び順
1. 「無料で作れる」と「無料で使える」は違う（ファーストビューの主題）
2. **サービス比較表**（Wix / Jimdo / ロリポップ！）
3. 各サービスの特徴と公式リンク（カードの羅列ではなく縦の編集記事）
4. 迷った読者向けの**2問の条件整理**（診断を売り文句にしない）
5. 初心者向けの読みもの
6. よくある質問
7. 編集・広告の透明性

## デザイン
- `--paper: #f7f5ef`, `--ink: #242421`, `--accent: #ad4930`
- 日本語の見出しにOS標準の明朝系フォント。本文は読みやすいゴシック。
- 最大幅1160px、本文の行間を広めに、スマホで2カラムを1カラムへ。
- 比較表は横スクロールで列内容を落とさない。
- Webフォントや外部画像CDNの読み込み不要。無料・高速・軽量を優先。

## 維持するもの
- 既存Google Search Console認証タグ
- A8.net承認済みの**素材001**計測URLと1x1タグ（トップ・詳細比較に各1組）
- リンク周辺の明瞭な「PR・広告」の表示
- `scripts/check_sources.py` および週次公式情報の監視
- 事実未確認のAI下書きを自動公開しない安全策
- Cloudflare Pagesの無料公開とGitHub Actionsの自動テスト

## ファイル構成
- `data/home-v3.html`：公開ホームページの本文（編集用ソース）
- `scripts/render_pages.py`：上記本文を読み、HTMLページを生成する
- `site/index.html`：GitHub/Cloudflareに配置する静的な公開ページ
- `site/assets/styles.css`：v3全ページ共通のデザイン
- `site/assets/app.js`：2問の条件整理
- `tests/test_project.py`：ページ構成、内部リンク、計測URL、Google認証の確認

## 品質確認
- GitHub Actions の `Test static site` でPythonのユニットテスト・ビルドを確認する
- Cloudflare公開トップで新しい見出しとA8リンクを検証する
- サイトデザイン変更でCVRや滞在時間が改善したとは、測定するまで断言しない
- 今後も順位/レビュー捏造やスパムSEOにはしない

## 今後の評価
- 公開後にスマホでの読みやすさ、表の横スクロール、2問の選択動作を目視確認
- Search Consoleの実測表示回数・クリック数、A8管理画面で実際の広告クリック・承認済み成果を評価
- データが少ない段階では利益や離脱率について大きな推論をしない
