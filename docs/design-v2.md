# AIサイト選び — UX / Design v2

更新日：2026-11-22

## 目的
検索して来た初心者に「何が分かるサイトか」を3秒で伝え、**目的の明確化 → 候補比較 → 公式条件確認 → 任意の申込**まで迷いにくい導線を作る。広告の存在は比較の順位づけに利用しない。

## 画面構成（公開済み）

1. HERO：『AIでホームページ。自分に合う作り方、ここで見つけよう。』
   - 主CTA『30秒で候補を探す』→ 2問診断
   - 副CTA『3つのサービスを見る』→ サービスカード
2. QUICK FINDER：作成方法＋予算の2問を入力し、候補と確認ポイントを表示
   - 無料公開を最優先した場合、無料体験のみのサービスを「無料で使い続けられる」と案内しない
3. CHOOSE YOUR STYLE：Wix / Jimdo / ロリポップ！AIホームページの用途別カード
   - ロゴを偽造せず、単色の頭文字で視覚的に識別
   - 事実は公式情報に基づき、未確認のランキング・数値評価・使用体験は掲載しない
   - **ロリポップのA8広告は『PR・広告』を明示した独立のエリア**に置く
4. AT A GLANCE：無料公開・作り方・独自ドメイン・費用の注意を表で比較
5. BEFORE YOU DECIDE：無料プランと無料体験／支払総額／ドメイン更新／移行性
6. LEARN MORE：初心者向けガイドと詳細比較へ誘導
7. FAQ：よくある質問
8. CLOSE：迷った読者を診断へ戻す
9. 編集方針：非使用レビューであること、広告・通常リンクの違いを開示

## デザインシステム

- ベース：白・淡いブルー。情報を読みやすく、比較・操作に視線が向く
- メイン：#1764a5（青）、補助：#149b9a（青緑）、アクセント：#f37d5d
- 文字：#182d46、本文・補助：#5e7185
- 角丸：10〜23px、軽いシャドウと細い境界線、セクション間の余白を広く
- モックアップはCSSだけで描画。実際のサービス画面を模倣したスクリーンショットではない
- スマホ：1列カード・横スクロールできる比較表・押しやすいCTA・見出しサイズ調整
- 入力はnative selectを利用し、キーボード操作とARIAライブリージョンに対応
- OSの動きを減らす設定（prefers-reduced-motion）を尊重

## 運用方針

- 個人情報を必要以上に計測しない。既存のGoogle認証とA8の正式タグを維持
- 広告素材は受領済みA8 text 001のみ。改変や架空の成果報酬URLは作らない
- 収益化の成果はA8.netの管理画面で確認し、クリックと成果発生の区別を守る
- 週次の公式情報監視を維持し、価格・仕様の自動書き換えは行わない
- 追加の有料サービス・独自ドメイン・課金APIは採用しない

## 公開後の評価

- Google Search Console：ページ別の表示回数、検索語、クリックの変化を確認
- A8.net：広告クリック数、承認済み成果、否認数を確認
- 2〜4週間後に「訪問者の困りごとに回答できているか」を見直す。直後の順位を成功と誤解しない
- SNSへの自動大量投稿、架空レビュー、広告の誤認誘導を避ける

## 変更箇所

- `site/index.html`：v2トップページ
- `site/compare.html`：比較ページの入口改善
- `site/assets/styles.css`：レスポンシブデザイン
- `site/assets/app.js`：2問ミニ診断
- `scripts/render_pages.py`：静的HTML再生成用の同等テンプレート
- `tests/test_project.py`：URL・広告・デザイン要素の回帰テスト

## 受入条件

1. 公開HTMLに新しい見出しと診断UIがある
2. ミニ診断で予算・目的の組み合わせに応じた候補が提示される
3. トップと比較にA8.netの正規広告URL・計測用画像が各1個存在する
4. PR・広告表記と通常の公式リンクが明確に分離されている
5. Googleサイト所有権確認タグを維持
6. Python unittestが全件成功
7. Cloudflare Pages公開URLが応答し、公開トップに新デザインと広告リンクがある

**注意**：デザイン改善による離脱率や売上上昇は測定前であり保証されない。
